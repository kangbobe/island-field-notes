# 岛屿之间

从新加坡出发的富国岛与科莫多交互旅行计划。

公开网站：https://kangbobe.github.io/island-field-notes/

选择目的地、日期、天数、人数、节奏和携程酒店，然后点击“生成我的完整计划”。船宿为科莫多的独立选项。

资料核对日：2026-10-25。机票、酒店和活动不保证余位，签证与海况以官方临行信息为准。小红书原帖受登录限制，未完成原帖核验。

index.html 为自包含静态页面，不收集个人证件。选择仅存在本浏览器。照片许可见 ATTRIBUTIONS.md。

新增：所有景点支持多图相册、缩略图切换和大图前后翻页；删除预算计算板块。

地图与时间：29处景点/酒店/交通点，支持按日查看、快艇/慢船时间、停留建议及坐标来源。交通区间为规划估算；虚线不是导航航线。地图底图需联网加载。

住宿讨论：2—5位成员统一录入人民币/人/晚最高愿付价、体验偏好和实际分房。每房最多2人，按同房均分换算间夜上限。8家候选提供携程、Agoda、Trip.com和官网链接；平台价格由使用者查询录入，不自动抓价。按每房、同日期与同条款比较，展示个人是否超出上限、候选酒店全组住宿费；日期/分房变化会暂停旧报价。选择酒店同步到日程和地图。科莫多船宿的2个船上夜独立计算。成员与报价仅保存在浏览器，不发布到仓库。

开发：`python3 build.py`生成内嵌全部照片与脚本的index.html；`node stay-math.test.cjs`检查分房预算与个人上限计算。
